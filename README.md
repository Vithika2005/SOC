# SentinelX

**SentinelX: Agentic SOC with Digital Twin-Based Autonomous Incident Response**

Final Year Project

## Overview

SentinelX is an AI-powered Security Operations Center (SOC) platform that integrates:

- Enterprise Infrastructure Simulation
- DevSecOps Security Assessment
- Runtime Threat Detection
- Multi-Agent AI Investigation
- Retrieval-Augmented Generation (RAG)
- Digital Twin Simulation
- Explainable Security Decision Support

This repository contains both the simulated enterprise environment and the SentinelX platform.
